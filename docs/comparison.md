# Reference vs recreation

Left: the Sales CRM reference (captured 2026-09-24, `docs/reference/screens/`). Right: our component rendered in the
catalogue preview (`docs/comparison/`). Components are rebuilt from the observed UI and the CRM's own CSS tokens, not
from screenshots or an embedded copy.

**Side-by-side images at the same height:** `docs/comparison/side-by-side/<slug>.png` (12 pairs, built by `node scripts/side-by-side.mjs`). Recreations are the real preview renders, also used as the locked-preview thumbnails (`packages/ui/thumbnails/`).

Other overall differences:

- **Font:** Geist is loaded from Google Fonts. The CRM self-hosts it through Next.js.
- **Motion:** we use one easing (`ease-crm` = the CRM's `power3-out`) and simple enter animations. The CRM's exact keyframes were not copied.
- **Business features are not rebuilt:** sorting and filtering data, trials, billing and invites.
